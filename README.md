# Простая Telegram CRM для арбитражной команды

Упрощённый MVP без Node.js, npm, package.json, React Mini App и отдельного backend. Всё работает прямо в Telegram-боте и хранится в локальной SQLite базе `crm.sqlite3`.

## Как запустить через PyCharm

1. Откройте проект в PyCharm.
2. Откройте `config.py`.
3. Вставьте токен бота в `BOT_TOKEN`.
4. Вставьте Telegram numeric ID админов в `ADMIN_IDS`.
5. Откройте `main.py` и нажмите Run.
6. Откройте своего бота в Telegram и отправьте `/start`.

Зависимости устанавливать не нужно: используется только стандартная библиотека Python.

## Логика регистрации

- Если Telegram ID пользователя есть в `ADMIN_IDS`, он автоматически становится `admin`.
- Если пользователь не зарегистрирован, бот показывает кнопку **Зарегистрироваться**.
- После нажатия заявка сохраняется в базу со статусом `pending`.
- Админам приходит уведомление в Telegram.
- Админ в меню **Заявки** назначает пользователю роль: `traffic` или `handler`.
- Для роли `traffic` бот дополнительно попросит ввести `traffic_id`.

## Роли

### Admin

- видит заявки;
- назначает роли;
- назначает `traffic_id` трафферам;
- видит общую статистику.

### Traffic

- видит обработчиков на смене;
- выбирает активного обработчика как цель трафика;
- не видит лиды;
- видит статистику по своему `traffic_id`.

### Handler

- выходит на смену / завершает смену;
- вручную добавляет лида;
- обязательно указывает `traffic_id`;
- видит только своих лидов;
- меняет статусы: `new`, `in_progress`, `closed`, `rejected`.

## Ключевые правила

- Лиды не создаются автоматически.
- Лид создаёт только обработчик вручную.
- `traffic_id` обязателен для каждого лида.
- Видимость обработчика для траффера зависит от смены.
- Все ключевые действия пишутся в аудит.
